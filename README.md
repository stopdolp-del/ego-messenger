# Local Messenger (Node.js + Express + WebSockets + MySQL)

Локальное десктопное/веб приложение для обмена сообщениями в реальном времени с поддержкой серверов, каналов, личных сообщений, а также интеграцией с MySQL / MariaDB (управление через HeidiSQL).

---

## 🛠 Требования к окружению

1. **Node.js** (версия 16 или выше)
2. **MySQL** или **MariaDB** (запущенный локально на порту `3306`)
3. **HeidiSQL** (утилита для управления базой данных)

---

## 🚀 Пошаговая инструкция по запуску

### Шаг 1. Настройка базы данных в HeidiSQL

1. Откройте **HeidiSQL**.
2. Создайте или выберите подключение к вашему локальному серверу MySQL/MariaDB:
   - **Хост (IP)**: `localhost` (или `127.0.0.1`)
   - **Пользователь**: `root`
   - **Пароль**: Ваш пароль от MySQL (если есть)
   - **Порт**: `3306`
3. Нажмите **"Открыть"** (Open).
4. Нажмите синюю кнопку **"Выполнить SQL"** (или выберите в меню *Файл -> Открыть файл SQL* и выберите файл `schema.sql` из папки проекта).
5. Также при запуске сервера `node server.js` база данных `messenger_db` и все таблицы будут проверены и созданы автоматически!

---

### Шаг 2. Конфигурация файла `.env`

В папке проекта откройте файл `.env` (или создайте его на основе `.env.example`) и проверьте данные подключения к вашей БД:

```env
PORT=3000
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=root
DB_NAME=messenger_db
```

*Если у вашего пользователя `root` в MySQL другой пароль, укажите его в строке `DB_PASSWORD`.*

---

### Шаг 3. Запуск сервера через CMD / Терминал

1. Откройте командную строку Windows (**CMD**) или Терминал.
2. Перейдите в директорию проекта:
   ```cmd
   cd C:\Users\hh13a\.gemini\antigravity\scratch\messenger-app
   ```
3. Установите необходимые зависимости:
   ```cmd
   npm install
   ```
4. Запустите сервер:
   ```cmd
   node server.js
   ```
   *Или альтернативная команда:*
   ```cmd
   npm start
   ```

5. В CMD вы увидите аналогичные логи подключения:
   ```text
   [DB SUCCESS] Connected to MySQL database "messenger_db" at localhost:3306
   [DB INITIALIZATION] Database tables verified / ready.

   ==================================================
   🚀 Messenger Server successfully launched!
   🌐 Server running at: http://localhost:3000
   📊 DB Host: localhost:3306
   ==================================================
   ```

---

### Шаг 4. Использование и проверка в браузере

1. Откройте браузер и перейдите по адресу: **`http://localhost:3000`**
2. **Регистрация / Вход**: Зарегистрируйте двух разных пользователей (например, `alex` и `maria`). Вы можете открыть два разных окна браузера (или вкладку в режиме Инкогнито).
3. **Поиск пользователей и добавление в контакты**:
   - В левой панели нажмите на значок **`+`** возле списка контактов.
   - Введите имя второго пользователя (например, `maria`) и нажмите **"Добавить"**.
   - Начните личный чат в реальном времени.
4. **Создание серверов и каналов**:
   - Нажмите значок **`+`** в самой левой панели серверов.
   - Введите название сервера (например, "Мой Сервер").
   - Создавайте текстовые каналы (например, `#flood`, `#news`) и общайтесь с участниками.

## ⚡ Проверка работы статусов из БД HeidiSQL

В приложении реализована динамическая синхронизация статусов с MySQL:

### 1. Проверка галочки подтверждения (`is_verified`):
- В HeidiSQL откройте таблицу `users`.
- Найдите нужного пользователя и установите значение в колонке `is_verified` равным **`1`**.
- Сохраните изменения в HeidiSQL.
- В течение 5 секунд возле имени пользователя в чатах, списки контактов, сообщении и профиле автоматически появится **синяя галочка `✓`**.

### 2. Проверка блокировки доступа (`is_banned`):
- В HeidiSQL откройте таблицу `users`.
- Найдите нужного пользователя и установите значение в колонке `is_banned` равным **`1`**.
- Сохраните изменения в HeidiSQL.
- Пользователь **мгновенно заблокируется**: отправка сообщений по WebSockets будет заблокирована, и на экране появится красный экран блокировки доступа с сообщением о бане.
- Установите `is_banned = 0` в HeidiSQL и нажмите *"Проверить статус повторно"* для разблокировки.

## 📂 Структура проекта

- `server.js` — главный сервер Express, подключение MySQL pool, WebSockets (Socket.io) handlers, REST API endpoints.
- `schema.sql` — SQL-скрипт создания базы данных и таблиц.
- `public/index.html` — главная страница приложения (HTML5 layout).
- `public/styles.css` — стили в стиле Discord/Slack, темная тема, баджи, плашки банов.
- `public/app.js` — клиентская логика, Socket.io события, динамическое обновление UI.
- `package.json` — зависимости Node.js.
